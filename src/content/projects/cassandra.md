## Visión General

**Cassandra** es un sistema operativo personal y centro de mando (*Personal HQ*) concebido para solucionar mi problema real: la sobrecarga ejecutiva y dispersión cognitiva entre tantos proyectos. Mientras las aplicaciones tradicionales imponen taxonomías rígidas y complejas, Cassandra estructura la operativa diaria mediante transiciones de estado explícitas y fricción mínima de captura.

## Arquitectura Técnica

- **Backend Ultraliviano en Go:** Construido con la biblioteca estándar de Go (`net/http`), compilado en un único binario autosuficiente que embebe los artefactos del cliente web mediante `embed.FS`. Consume menos de 25MB de memoria RAM en reposo.
- **Frontend SPA en Angular 22:** Uso extensivo de *Signals* y componentes *standalone* para un renderizado granular sin ciclos de detección de cambios innecesarios. Diseño de interfaz con Tailwind CSS v4 enfocado en contrastes legibles y tipografía clara.
- **Capa de Datos en PostgreSQL:** Esquema relacional con índices B-tree optimizados para agregaciones de balance financiero, seguimiento de tareas y bitácoras temporales.
- **Empaquetado Multiplataforma con Capacitor:** Permite compilar y distribuir directamente la SPA de Angular como ejecutable para Android, manteniendo una única base de código para escritorio y móvil.

## Principales Logros

- Reducción del tiempo de inicio de la aplicación a milisegundos gracias al empaquetado como binario estático.
- Modelo de interacción de baja fricción que minimiza los clics necesarios para registrar tareas o notas de contexto crítico.
- Sincronización transparente entre la instancia local de escritorio y el dispositivo móvil.
