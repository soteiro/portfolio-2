## Descripción del Proyecto

Sistema de diseño integral orientado a la accesibilidad universal (WCAG 2.2 nivel AAA) y coherencia visual multiplataforma.

### Puntos Destacados
- **Accesibilidad Primero:** Foco de teclado visible, atributos ARIA verificados y contraste optimizado.
- **Tokens de Diseño:** Variables CSS para espaciado, colores y tipografía adaptables a temas claro y oscuro.
- **Storybook:** Catálogo interactivo documentando cada estado de los componentes.
